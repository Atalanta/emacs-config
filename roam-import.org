* Overview

A small functional pipeline that converts an Obsidian-shaped
Markdown vault into roam nodes. Pure stages threaded through a
driver; side effects (read, shell-out, write) live at the edges.

The conversion uses =pandoc= as the heavy lifter — markdown →
org syntax, wikilink shape, heading shift, YAML →
=#+title:= — and a small post-processing pass to rewrite
=[[file:slug][text]]= links into =[[id:UUID][text]]= using the
slug→UUID map produced in a first pass.

This file tangles to =sns-emacs-modules/sns-roam-import.el= and
is loaded via =(require 'sns-roam-import)= once we wire it.
Tangle:

#+begin_src sh :tangle no
emacs --batch --load org --eval '(org-babel-tangle-file "roam-import.org")'
#+end_src

** Pipeline shape

Each stage takes a plist, returns a plist; no shared mutable
state.

#+begin_example
md-path → :read-source       → (:yaml :body :path)
       → :parse-yaml         → (:yaml-title :yaml-aliases :yaml-date :body :path)
       → :derive-title       → (:title :title-source :…)
       → :derive-created     → (:created-time :created-source :…)
       → :pandoc             → (:org-body :…)
       → :parse-body-elements → (:elements :…)
       → :rewrite-wikilinks  → (:elements :…)
       → :create-node        → (:id :title :file :aliases)
#+end_example

The driver =sns-roam-import-from-markdown= threads these via
=thread-last= and returns the final plist. Two-pass orchestration
(slug→UUID map built in a first pass) lives in
=sns-roam-import-vault=.

*** Two-stage discipline: import liberally, mark conservatively, promote deliberately

The importer's job is to produce a *structurally valid* roam node
from arbitrary markdown — not to judge whether that node deserves
to exist. Every imported file:

- Gets a UUID (always — minted at import).
- Gets a title (cascade: yaml =title:= → first H1 from pandoc AST
  → filename slug humanised — never errors).
- Gets a CREATED time (cascade: yaml =date:= → magit first-touch
  → import-time — never errors).
- Gets =:KIND: imported= verbatim. Always. The importer never
  trusts foreign =kind:= metadata; promoting an imported node to
  =permanent= is a *curation* act, performed downstream against
  the atomic-notes heuristic.

This separation buys clean composition: =roam-distill= (future)
can walk =:KIND: imported= as a triage queue without the importer
having pre-judged anything.

The cascade decisions are logged via =message= so vault hygiene
issues (a file falling back to filename-slug, a file with no
discoverable creation date) are visible without being noisy.

* Pure stages

Each function below is a pipeline stage. Read them as a list of
transformations; the driver wires them together.

** Read source

Read the =.md= file and split YAML frontmatter from body. YAML
is delimited by =---= on its own line at the top.

#+begin_src emacs-lisp
(defun sns-roam-import--read-source (path)
  "Return (:path :yaml :body) for the markdown file at PATH.

If the file has no YAML frontmatter, =:yaml= is the empty string
and =:body= is the whole file."
  (let ((raw (with-temp-buffer
               (insert-file-contents path)
               (buffer-string))))
    (if (string-match "\\`---\n\\(\\(?:.\\|\n\\)*?\\)\n---\n\\(\\(?:.\\|\n\\)*\\)\\'" raw)
        (list :path path
              :yaml (match-string 1 raw)
              :body (match-string 2 raw))
      (list :path path :yaml "" :body raw))))
#+end_src

** Parse YAML

Extract =title=, =aliases=, and =date= using =yaml.el= — a real
YAML parser, not a regex. Tags, =type=, and =kind= are
deliberately ignored: vault-local labels don't carry meaning into
this slipbox, and =kind= in particular is *never* honoured — see
the discipline notes for why.

This stage no longer errors on missing fields. It extracts what
it can find and writes the results under =:yaml-title=,
=:yaml-aliases=, and =:yaml-date= (any of which may be nil).
Downstream cascades resolve the canonical =:title= and
=:created-time=; this stage is data-extraction only, not
decision-making.

=yaml-parse-string= returns nested hash tables by default; we
ask for alists so plist threading stays simple. Aliases come
back as a vector — flatten to a list.

#+begin_src emacs-lisp
(defun sns-roam-import--parse-yaml (input)
  "Parse YAML in INPUT plist's =:yaml= and add =:yaml-title=,
=:yaml-aliases=, =:yaml-date=. Any may be nil; never errors on
missing fields — title and created derivation cascades resolve
defaults downstream."
  (let* ((yaml-str (plist-get input :yaml))
         (parsed   (if (string-empty-p yaml-str)
                       nil
                     (yaml-parse-string yaml-str
                                        :object-type 'alist
                                        :sequence-type 'list)))
         (title    (alist-get 'title parsed))
         (aliases  (alist-get 'aliases parsed))
         (date     (alist-get 'date parsed)))
    (append (list :yaml-title title
                  :yaml-aliases aliases
                  :yaml-date date)
            input)))
#+end_src

** Derive title (cascade)

Resolve the canonical =:title= via a three-step cascade:

1. =:yaml-title= if present.
2. First H1 from the body, extracted via pandoc's JSON AST so
   code-fenced lines, blockquoted hashes, and setext-style H1s
   (=Title\n=====) are all handled correctly. Inline emphasis,
   code spans, and links inside the heading text are flattened
   to plain text by a second pandoc invocation (json → plain).
3. Filename slug humanised (=what-is-this= → =What Is This=).

The cascade always succeeds — every markdown file can yield a
title. Records =:title-source= alongside the result
(=:yaml=, =:h1=, =:filename=) for the message log and for
downstream curation.

Why pandoc twice rather than a regex on the body or
=markdown-mode='s primitives: pandoc *is* the markdown parser we
already trust for body conversion, and asking it to also identify
the H1 keeps a single source of truth for grammar interpretation.
Tree-sitter is the principled future replacement (see
[[file:~/.claude/projects/-Users-stephen-nelsonsmith-Developer-aldi-compass/memory/roam_import_treesitter_future.md][roam-import-treesitter-future]] memory) but isn't ready yet.

#+begin_src emacs-lisp
(defun sns-roam-import--shell-pandoc-to-json (markdown)
  "Run pandoc on MARKDOWN, return the JSON AST as a string.
Errors if pandoc exits non-zero."
  (with-temp-buffer
    (let ((exit (let ((coding-system-for-write 'utf-8))
                  (call-process-region
                   markdown nil "pandoc" nil t nil
                   "-f" "markdown+wikilinks_title_after_pipe-auto_identifiers-smart"
                   "-t" "json"))))
      (unless (eq exit 0)
        (error "sns-roam-import: pandoc -t json exited %s\n%s"
               exit (buffer-string)))
      (buffer-string))))

(defun sns-roam-import--shell-pandoc-from-json-to-plain (json)
  "Run pandoc to convert JSON AST string to plain text.
Used to flatten inline emphasis / code spans / links inside an
H1 heading to plain text."
  (with-temp-buffer
    (let ((exit (let ((coding-system-for-write 'utf-8))
                  (call-process-region
                   json nil "pandoc" nil t nil
                   "-f" "json"
                   "-t" "plain"
                   "--wrap=none"))))
      (unless (eq exit 0)
        (error "sns-roam-import: pandoc -f json -t plain exited %s\n%s"
               exit (buffer-string)))
      (string-trim (buffer-string)))))

(defun sns-roam-import--first-h1-block (blocks)
  "Walk pandoc AST BLOCKS list for the first level-1 Header.
Returns the Header alist, or nil. Pure: only inspects structure."
  (cl-loop for block across blocks
           when (and (equal (alist-get 't block) "Header")
                     (let ((c (alist-get 'c block)))
                       ;; Header c is [level, attrs, inlines]
                       (and (vectorp c)
                            (= (length c) 3)
                            (= (aref c 0) 1))))
           return block))

(defun sns-roam-import--extract-first-h1 (markdown)
  "Return the plain-text content of the first H1 in MARKDOWN, or nil.
Uses pandoc's AST so all markdown grammar quirks (code fences,
blockquoted hashes, setext H1s) are handled correctly."
  (let* ((json   (sns-roam-import--shell-pandoc-to-json markdown))
         (ast    (json-parse-string json :object-type 'alist
                                    :array-type 'array))
         (blocks (alist-get 'blocks ast))
         (h1     (sns-roam-import--first-h1-block blocks)))
    (when h1
      ;; Render just this Header back to plain text. Wrap in a
      ;; minimal Pandoc envelope so pandoc -f json accepts it.
      (let* ((envelope `((pandoc-api-version . [1 23 1])
                         (meta . ,(make-hash-table :test 'equal))
                         (blocks . [,h1])))
             (envelope-json (json-serialize envelope)))
        (sns-roam-import--shell-pandoc-from-json-to-plain envelope-json)))))

(defun sns-roam-import--humanise-slug (slug)
  "Turn a filename slug into a humanised title.
=what-is-this= → =What Is This=; =atomic-notes= → =Atomic Notes=.
Splits on hyphens and underscores, title-cases each word."
  (mapconcat #'capitalize
             (split-string slug "[-_]+" t)
             " "))

(defun sns-roam-import--derive-title (input)
  "Resolve canonical =:title= via cascade; add =:title-source=.
Cascade: =:yaml-title= → first H1 of body → humanised filename slug.
Logs the source via =message= so vault hygiene issues are visible."
  (let* ((yaml-title (plist-get input :yaml-title))
         (body       (plist-get input :body))
         (path       (plist-get input :path))
         (h1         (and (not yaml-title)
                          (sns-roam-import--extract-first-h1 body)))
         (slug       (file-name-base path))
         (title      (or yaml-title
                         h1
                         (sns-roam-import--humanise-slug slug)))
         (source     (cond (yaml-title :yaml)
                           (h1         :h1)
                           (t          :filename))))
    (message "sns-roam-import: title for %s from %s → %S"
             (file-name-nondirectory path) source title)
    (append (list :title title :title-source source) input)))
#+end_src

** Derive created time (cascade)

Resolve the canonical =:created-time= (an emacs internal time
value) via a three-step cascade:

1. =:yaml-date= if present and parseable as ISO 8601.
2. Git first-touch — the author date of the first commit that
   added the file, via =magit-git-string=.
3. Import-time — =current-time=.

The cascade always succeeds. =current-time= is the honest
fallback when we have nothing better; we never lie about file
mtime (which copy operations reset).

Records =:created-source= (=:yaml=, =:git=, =:now=) for the
message log.

#+begin_src emacs-lisp
(defun sns-roam-import--parse-yaml-date (date)
  "Best-effort parse of a yaml DATE field to an emacs time value.
DATE may be a string (ISO 8601 or simple =YYYY-MM-DD=) or already
a parsed value from yaml.el. Returns nil on failure rather than
erroring — the cascade has further fallbacks."
  (cond
   ((null date) nil)
   ((stringp date)
    (or (ignore-errors (parse-iso8601-time-string date))
        ;; yaml.el sometimes leaves =YYYY-MM-DD= as a bare string
        ;; that parse-iso8601-time-string rejects; pad to a full
        ;; ISO timestamp and retry.
        (and (string-match-p "\\`[0-9]\\{4\\}-[0-9]\\{2\\}-[0-9]\\{2\\}\\'" date)
             (ignore-errors
               (parse-iso8601-time-string (concat date "T00:00:00+00:00"))))))
   ;; yaml.el may already have decoded a date to a list — we don't
   ;; rely on that path, so fall through to nil.
   (t nil)))

(defun sns-roam-import--git-first-touch (path)
  "Return the time the file at PATH was first added to git, or nil.
Uses =magit-git-string= so process management and error handling
go through the canonical magit interface; nil on any failure
(file not in a repo, file untracked, magit not loaded)."
  (when (require 'magit nil t)
    (let* ((default-directory (file-name-directory path))
           (iso (ignore-errors
                  (magit-git-string "log" "--diff-filter=A" "--follow"
                                    "--format=%aI" "-1" "--"
                                    (file-name-nondirectory path)))))
      (when (and iso (not (string-empty-p iso)))
        (ignore-errors (parse-iso8601-time-string iso))))))

(defun sns-roam-import--derive-created (input)
  "Resolve canonical =:created-time= via cascade; add =:created-source=.
Cascade: =:yaml-date= → magit first-touch → =current-time=.
Logs the source via =message=."
  (let* ((yaml-date  (plist-get input :yaml-date))
         (path       (plist-get input :path))
         (yaml-time  (sns-roam-import--parse-yaml-date yaml-date))
         (git-time   (and (not yaml-time)
                          (sns-roam-import--git-first-touch path)))
         (time       (or yaml-time git-time (current-time)))
         (source     (cond (yaml-time :yaml)
                           (git-time  :git)
                           (t         :now))))
    (message "sns-roam-import: created for %s from %s → %s"
             (file-name-nondirectory path)
             source
             (format-time-string "[%Y-%m-%d %a %H:%M]" time))
    (append (list :created-time time :created-source source) input)))
#+end_src

** Pandoc

Shell out to =pandoc= with the four flags that do most of the
clean-up:

- Reader: =markdown+wikilinks_title_after_pipe-auto_identifiers-smart= —
  parse =[[X|Y]]= wikilinks; suppress =:CUSTOM_ID:= drawers;
  disable curly-quote conversion on input.
- Writer: =org-special_strings= — keep real em-dash characters
  (=—=) in the output instead of converting them to org's =---=
  shortcut. Source markdown already uses the right characters;
  no point round-tripping them through ASCII shortcuts.
- =--shift-heading-level-by=-1= — drop the H1 (which duplicated
  =#+title:= anyway) and demote everything else.
- =--wrap=preserve= — no line-rewrapping; preserves authored
  paragraph shape.
- =-s= with metadata-block extension — emits =#+title:= from
  YAML automatically (we'll discard pandoc's =#+title:= because
  we already have ours from =:parse-yaml=, and they should match).

Pandoc takes input on stdin to avoid temp files.

#+begin_src emacs-lisp
(defun sns-roam-import--shell-pandoc (markdown)
  "Run pandoc on MARKDOWN string, return the org-formatted output.
Errors if pandoc exits non-zero."
  (with-temp-buffer
    (let ((exit (let ((coding-system-for-write 'utf-8))
                  (call-process-region
                   markdown nil "pandoc" nil t nil
                   "-f" "markdown+wikilinks_title_after_pipe-auto_identifiers-smart"
                   "-t" "org-special_strings"
                   "--shift-heading-level-by=-1"
                   "--wrap=preserve"))))
      (unless (eq exit 0)
        (error "sns-roam-import: pandoc exited %s\n%s" exit (buffer-string)))
      (buffer-string))))

(defun sns-roam-import--strip-pandoc-title (org-output)
  "Remove the leading =#+title:= line emitted by pandoc -s, if present.
We use the title from YAML directly to avoid mismatch surprises."
  (replace-regexp-in-string "\\`#\\+title:.*\n+" "" org-output))

(defun sns-roam-import--pandoc (input)
  "Run pandoc on INPUT's =:body= and add =:org-body=."
  (let* ((body     (plist-get input :body))
         (org      (sns-roam-import--shell-pandoc body))
         (cleaned  (sns-roam-import--strip-pandoc-title org)))
    (append (list :org-body cleaned)
            (cl-loop for (k v) on input by #'cddr
                     unless (eq k :body)
                     append (list k v)))))
#+end_src

** Rewrite wikilinks

Pandoc emits =file:= links for every Obsidian wikilink. We
walk the parsed AST (post =parse-body-elements=) and rewrite
each link element structurally — no regex over pandoc's text.

- Resolved slug (in UUID-MAP) → =[[id:UUID][TEXT]]=.
- Unresolved slug → =[[TEXT]]=, a fuzzy roam-resolvable link
  that preserves Obsidian's autovivification semantics (the
  link declares "this note should exist someday"; roam
  resolves it the moment a node with matching title or alias
  is created).
- Non-file links (=id:=, =https:=, etc.) pass through.

When the original Obsidian link had no display text
(=[[wikilinks]]=), pandoc emits a bare =[[file:wikilinks]]=
with no children; we use the slug as the fuzzy link target
and omit the display text. When display text differs from
slug we keep the slug as link target and the text as display.

#+begin_src emacs-lisp
(defun sns-roam-import--rewrite-link-ast (link uuid-map)
  "Return a rewritten LINK element if it's a file: link, else LINK unchanged.
Preserves =:post-blank= from the original so trailing whitespace
between the link and following text isn't dropped on re-emit
(otherwise =[[…]] foo= becomes =[[…]]foo=)."
  (if (string= (org-ml-get-property :type link) "file")
      (let* ((slug     (org-ml-get-property :path link))
             (children (org-ml-get-children link))
             (text     (and (stringp (car-safe children))
                            (car children)))
             (uuid     (cdr (assoc slug uuid-map)))
             (post-blank (org-ml-get-property :post-blank link))
             (rebuilt (cond
                       (uuid (org-ml-build-link (concat "id:" uuid)
                                                (or text slug)))
                       ((and text (not (string= text slug)))
                        (org-ml-build-link slug text))
                       (t (org-ml-build-link (or text slug))))))
        (org-ml-set-property :post-blank post-blank rebuilt))
    link))

(defun sns-roam-import--rewrite-wikilinks-ast (elements uuid-map)
  "Return ELEMENTS (list of org-ml AST nodes) with file: links rewritten.
Each top-level element's link descendants are rewritten via
`sns-roam-import--rewrite-link-ast'."
  (mapcar
   (lambda (element)
     (org-ml-match-map
      '(:any * link)
      (lambda (l) (sns-roam-import--rewrite-link-ast l uuid-map))
      element))
   elements))

(defun sns-roam-import--rewrite-wikilinks (uuid-map)
  "Return a stage function that rewrites wikilinks (AST stage).
Reads =:elements= from input plist, rewrites file: links via
UUID-MAP, writes the result back to =:elements=."
  (lambda (input)
    (let ((rewritten (sns-roam-import--rewrite-wikilinks-ast
                      (plist-get input :elements)
                      uuid-map)))
      (plist-put (copy-sequence input) :elements rewritten))))
#+end_src

** Create node

The single side-effecting stage. =create-node= parses the
pandoc-emitted org body into an AST and hands it to
=sns-roam-create-node=, which builds the file end-to-end via
org-ml. Aliases are passed through so they land in the property
drawer at write time — no second pass over the just-written
file.

The AST conversion flattens the parsed =org-data= node into the
list of elements =sns-roam-create-node= expects: the leading
section's children (paragraphs etc.) followed by any sibling
headlines. =sns-roam-create-node= re-splits them on its end
into "section children" (drawer + keyword + paragraphs) and
"sibling headlines"; the round-trip survives because that's
exactly the structure org-mode itself imposes.

#+begin_src emacs-lisp
(defun sns-roam-import--parse-body-elements-from-string (org-body)
  "Parse ORG-BODY (a string of org-formatted text) into a flat list
of org-ml AST nodes suitable for `sns-roam-create-node'.

The leading section's paragraph-ish children are unwrapped (so
they go into our header section); any sibling headlines pass
through untouched."
  (let* ((parsed (with-temp-buffer
                   (insert org-body)
                   (org-ml-parse-this-buffer)))
         (children (org-ml-get-children parsed)))
    (cl-mapcan (lambda (child)
                 (if (eq (org-ml-get-type child) 'section)
                     (org-ml-get-children child)
                   (list child)))
               children)))

(defun sns-roam-import--parse-body-elements (input)
  "Pipeline stage: parse INPUT plist's =:org-body= into =:elements=.
Drops =:org-body= from the output plist; downstream stages work
on the AST list under =:elements=."
  (let ((elements (sns-roam-import--parse-body-elements-from-string
                   (plist-get input :org-body))))
    (append (list :elements elements)
            (cl-loop for (k v) on input by #'cddr
                     unless (eq k :org-body)
                     append (list k v)))))

(defun sns-roam-import--create-node (input)
  "Create a roam node from INPUT, returning (:id :title :file :aliases).
Body comes from =:elements= (already AST). KIND is hard-coded
=imported= for every imported note — the importer never trusts
foreign =kind:= metadata, and =permanent= must be earned
downstream by curation against the atomic-notes heuristic. If
INPUT has a pre-assigned =:id=, it's used verbatim; otherwise
=sns-roam-create-node= generates one. Aliases pass through to the
property drawer at write time. =:created-time= (resolved by the
=derive-created= stage) is threaded into =sns-roam-create-node=
so the file's :CREATED: property and 14-digit prefix both reflect
the authored date — both formatted from the same internal time
value."
  (let* ((aliases (plist-get input :yaml-aliases))
         (created (sns-roam-create-node
                   (plist-get input :title)
                   "imported"
                   (plist-get input :elements)
                   (plist-get input :id)
                   aliases
                   (plist-get input :created-time))))
    (append created (list :aliases aliases))))
#+end_src

* Drivers

** Single-file import

For testing one file at a time. =UUID-MAP= is the slug→UUID
alist used for wikilink resolution; pass =nil= when there's
nothing to resolve. =PRE-ASSIGNED-ID= is optional — pass a UUID
to use a specific one (the vault driver does this); omit to let
=sns-roam-create-node= generate a fresh UUID.

#+begin_src emacs-lisp
(defun sns-roam-import--inject-id (input pre-assigned-id)
  "Add =:id= PRE-ASSIGNED-ID to INPUT plist if non-nil; else return as-is.
Lets the create-node stage pick up the pre-assigned UUID
without any temporal coupling between caller and callee."
  (if pre-assigned-id
      (plist-put (copy-sequence input) :id pre-assigned-id)
    input))

(defun sns-roam-import-from-markdown (path uuid-map &optional pre-assigned-id)
  "Import the markdown file at PATH as a roam node.
UUID-MAP is the slug→UUID alist for wikilink resolution.
PRE-ASSIGNED-ID, if non-nil, is used verbatim as the new node's
UUID; otherwise a fresh one is generated. Returns the final
plist (:id :title :file :aliases)."
  (thread-last (sns-roam-import--read-source path)
               (sns-roam-import--parse-yaml)
               (sns-roam-import--derive-title)
               (sns-roam-import--derive-created)
               (sns-roam-import--pandoc)
               (sns-roam-import--parse-body-elements)
               (funcall (sns-roam-import--rewrite-wikilinks uuid-map))
               ((lambda (input) (sns-roam-import--inject-id input pre-assigned-id)))
               (sns-roam-import--create-node)))
#+end_src

** Two-pass vault import

Pass 1: derive a slug→UUID alist by generating one UUID per
markdown file, keyed by filename-base. Pure data.

Pass 2: thread each file through =sns-roam-import-from-markdown=
with the map and its pre-assigned UUID. Each call honours its
own UUID via the explicit argument — no dynamic-state tricks.

#+begin_src emacs-lisp
(defun sns-roam-import--md-slug (path)
  "Return the slug for an Obsidian markdown file, derived from filename.
Obsidian wikilinks resolve by filename-without-extension, so
that's what we use as the map key."
  (file-name-base path))

(defun sns-roam-import--build-uuid-map (md-paths)
  "Return alist mapping each PATH's slug to a freshly-generated UUID.
Pure — no files touched."
  (mapcar (lambda (p)
            (cons (sns-roam-import--md-slug p) (org-id-new)))
          md-paths))

(defun sns-roam-import-vault (md-paths)
  "Import every markdown file in MD-PATHS as a roam node.
Two-pass: first derives a slug→UUID map, then threads each file
through the full pipeline carrying its pre-assigned UUID so
intra-vault wikilinks resolve correctly. Returns a list of
final plists, one per file."
  (let ((uuid-map (sns-roam-import--build-uuid-map md-paths)))
    (mapcar (lambda (p)
              (let ((pre-uuid (cdr (assoc (sns-roam-import--md-slug p)
                                          uuid-map))))
                (sns-roam-import-from-markdown p uuid-map pre-uuid)))
            md-paths)))
#+end_src

* Discipline notes

- *Pure stages, side effects at the edges.* Read at the start,
  write at the end; everything in between transforms plists.
- *Plist threading via =thread-last=.* No deep nesting, no
  intermediate variable churn. The driver reads top-to-bottom.
- *No magic globals.* UUID-MAP is an explicit argument
  everywhere; never a dynamic-let or top-level state.
- *Two-pass vault import keeps wikilink resolution honest.*
  Pass 1 produces the map purely; pass 2 honours it by passing
  each file's pre-assigned UUID as an explicit argument all the
  way down to =sns-roam-create-node=. No dynamic state, no
  =cl-letf=, no temporal coupling between caller and callee.
- *Title is always derivable.* Three-step cascade
  (yaml → first H1 → humanised filename slug) guarantees every
  markdown file produces a valid roam node. The =:title-source=
  key carries provenance for downstream curation; cascade
  decisions are logged via =message=.
- *Created time is always derivable.* Three-step cascade
  (yaml date → magit first-touch → import-time) gives the most
  honest authored date we can find. The two timestamp shapes
  (Org bracket form for =:CREATED:=, 14-digit prefix for the
  filename) are both formatted from the same internal time
  value via =format-time-string= — never round-tripped through
  string parsing.
- *Soft failure on unresolved wikilinks.* Logged via =warn=,
  link left as-is. Reasonable because we may import in stages
  or against a vault with external references.
- *KIND hard-coded =imported= — never derived from input.* The
  importer's job is to produce a structurally valid roam node;
  judging whether a node is =permanent= belongs to curation,
  performed downstream against the atomic-notes heuristic.
  Foreign =kind:= metadata in yaml is silently ignored — we
  never trust strangers' classifications. Two-stage discipline:
  import liberally, mark conservatively, promote deliberately.
